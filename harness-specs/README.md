# Harness spec packs

Dated, reviewed snapshots of each harness's agent-config surface, one file
per harness (`claude.md`, `codex.md`, `devin.md`, `opencode.md`). These are
the evidence behind the emitters in `lib/emit-*.sh`:

- Phase A (the `loom` skill) refreshes a pack when a harness releases a
  config change — live docs first, live probes when the docs are ambiguous.
- Phase B (`loom.sh`) is deterministic and never reads these files at
  runtime; the packs justify what the emitters hardcode.

Every claim in a pack carries a source URL or a reference to a live probe.
A pack older than `spec_pack_max_age_days` (default 30) prints a staleness
warning when loom runs (non-blocking — refreshing is a Phase A decision,
not a commit blocker).

`GAPS.md` is generated by loom on every run into the directory named by
`paths.gaps_file` (default: this directory): anything the canonical config
expresses that a harness cannot, with the compensating control.

The packs shipped here were seeded from live conformance probes run in the
`sre-stack` repository on 2026-09-03. Treat them as a starting point and
re-verify on your first Phase A run.
